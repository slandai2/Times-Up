# Times-Up
The procrastination website that will hold you accountable.
# What is it?
'Time's Up!' is a website that works to encourage building healthy schedule habits. When a user opens the site, they will have an option of 3 games to choose from. Before the user starts playing, they will set a timer for how long they will allow themself to play. Once that timer ends, they will be blocked from interacting with the website for an hour. This hour break is intended to encourage users to start or return to the task they have been avoiding.
